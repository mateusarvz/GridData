# Estrutura De Pastas

## Raiz

Na raiz do projeto ficam:

- documentação
- configuração do Git
- arquivos de lock
- pasta `backend`
- pasta `frontend`
- scripts e notas de suporte

## Backend

`backend/` concentra toda a lógica do servidor.

Subpastas principais:

- `app/`
- `alembic/`
- `scripts/`
- `tests/`

## Frontend

`frontend/` concentra a aplicação visual.

Subpastas principais:

- `src/components/`
- `src/services/`
- `src/store/`
- `src/types/`
- `src/utils/`

## Documentação

`docs/` agora funciona como base de leitura humana.

Os arquivos foram pensados para leitura sequencial:

- visão geral
- backend
- frontend
- módulos
- segurança
- fluxo de dados
- estrutura de pastas
